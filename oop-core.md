# Фундаментальные концепции ООП

### 1. Классы и Объекты

**Определение:**

Класс — это пользовательский ссылочный тип данных (`reference type`), служащий чертежом (шаблоном) для создания объектов. Объект — это конкретный экземпляр класса, выделяемый в динамической памяти (в куче / `Heap`).

**Суть простыми словами:**

Класс — это чертеж здания, а объект — само построенное здание. Класс задает, *какие свойства и методы* будут у объекта, а объект хранит *конкретные значения*.

**Пример:**

```csharp
// Класс (чертеж)
public class Animal
{
    public string Name { get; set; }
    public double Weight { get; set; }

    public Animal(string name, double weight)
    {
        Name = name;
        Weight = weight;
    }

    public void MakeSound() => Console.WriteLine($"{Name} издает звук.");
}

// Объект (экземпляр)
Animal dog = new Animal("Шарик", 12.5);
dog.MakeSound();

```

### 2. Инкапсуляция

**Определение:**

Концепция ООП, объединяющая данные (поля) и методы для работы с ними внутри одного класса, а также ограничивающая прямой доступ к внутреннему состоянию объекта извне (сокрытие реализации).

**Суть простыми словами:**

Капсула защищает внутренности объекта от некорректного изменения снаружи. Доступ к полям предоставляется только через контролируемые точки (свойства и методы), которые валидируют входящие данные.

**Пример:**

```csharp
public class BankAccount
{
    // Сокрытое поле (инкапсулированное состояние)
    private decimal _balance;

    // Публичное свойство только для чтения
    public decimal Balance => _balance;

    // Метод контролирует корректность изменения состояния
    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("Сумма должна быть больше 0");
        _balance += amount;
    }
}

```

### 3. Наследование

**Определение:**

Механизм, позволяющий создавать новый (производный/дочерний) класс на основе существующего (базового/родительского). Производный класс автоматически получает доступ к членам базового класса (с учетом модификаторов доступа).

**Суть простыми словами:**

Позволяет переиспользовать код и выстраивать иерархию типов от общего к частному. В C# поддерживается только **одиночное наследование классов**, а модификатор `protected` открывает доступ членам класса внутри его наследников, но закрывает их от внешнего мира.

**Пример:**

```csharp
public class Animal
{
    protected string Name; // Доступно в Animal и его наследниках

    public Animal(string name) => Name = name;

    public void Eat() => Console.WriteLine($"{Name} ест.");
}

public class Dog : Animal // Dog наследует Animal
{
    public Dog(string name) : base(name) {}

    public void Bark() => Console.WriteLine($"{Name} лает: Гав!");
}

```

### 4. Полиморфизм

**Определение:**

Способность объектов разных классов с одинаковым интерфейсом или базовым типом предоставлять различную реализацию методов.

**Суть простыми словами:**

Единый вызов метода ведет себя по-разному в зависимости от того, объект какого именно дочернего класса его выполняет.

* **Динамический (Runtime):** переопределение виртуальных методов (`virtual` / `override`).
* **Статический (Compile-time):** перегрузка методов (`Overloading`).

**Пример:**

```csharp
public abstract class Animal
{
    public string Name { get; set; }
    public Animal(string name) => Name = name;

    public virtual void MakeSound() => Console.WriteLine("Издает общий звук.");
}

public class Dog : Animal
{
    public Dog(string name) : base(name) {}
    public override void MakeSound() => Console.WriteLine($"{Name} лает: Гав!");
}

public class Cat : Animal
{
    public Cat(string name) : base(name) {}
    public override void MakeSound() => Console.WriteLine($"{Name} мяукает: Мяу!");
}

// Полиморфный вызов:
List<Animal> zoo = new List<Animal> { new Dog("Шарик"), new Cat("Мурчик") };
foreach (Animal animal in zoo)
{
    animal.MakeSound(); // Каждый объект выполнит СВОЮ версию метода!
}

```

### 5. Абстракция

**Определение:**

Выделение только существенных характеристик объекта для текущей задачи и игнорирование несущественных деталей реализации.

**Суть простыми словами:**

Абстракция задает общий контракт (что должен делать объект), не вдаваясь в конкретику (как именно он это делает). Абстрактный класс (`abstract`) **нельзя создать через `new**`, он может содержать как абстрактные методы без тела, так и готовые методы с общей логикой.

**Пример:**

```csharp
public abstract class Animal
{
    public string Name { get; set; }
    public Animal(string name) => Name = name;

    // Абстрактный метод: обязателен к реализации в дочерних классах
    public abstract void Eat();

    // Обычный метод с готовой логикой
    public void Sleep() => Console.WriteLine($"{Name} спит.");
}

public class Eagle : Animal
{
    public Eagle(string name) : base(name) {}

    public override void Eat() => Console.WriteLine($"{Name} ест рыбу.");
}

```

### 6. Ассоциация: Композиция и Агрегация

**Определение:**

Ассоциация — это связь между классами по принципу «состоит из» / «имеет» (`Has-A`). Делится на два вида в зависимости от **управления жизненным циклом** вложенного объекта.

**Суть простыми словами:**

* **Композиция (Сильная связь):** Объект-часть создается внутри целого и уничтожается вместе с ним. Часть не может существовать без целого.
* **Агрегация (Слабая связь):** Объект-часть создается снаружи и передается в целое (через конструктор/метод). Часть может существовать независимо от целого.

**Пример:**

```csharp
public class Heart { /* ... */ }
public class Passport { /* ... */ }

public class Person
{
    private Heart _heart;       // КОМПОЗИЦИЯ: Сердце создается внутри человека
    private Passport _passport; // АГРЕГАЦИЯ: Паспорт передается извне

    public Person(Passport passport)
    {
        _heart = new Heart();   // Человек сам управляет жизненным циклом сердца
        _passport = passport;   // Паспорт существовал до человека и может остаться после
    }
}

```
